👥 Visor de Personajes

🔄 En Desarrollo

Esta herramienta permite visualizar en 3D todos los personajes del juego. Rota con mouse, zoom con rueda, cambia de pose, y toma screenshots para validación.

Estado actual: Plantilla lista. Implementación en progreso (Fase 2).

📋 Plan de Implementación

✅
Fase 1: Exportador básico

Descarga modelos como .glb. Accesible en /creador/exportador/

🔄
Fase 2: Visor de personajes (AHORA)

Carga GLB desde public/models/ o usa procedurales. 3D viewer con rotación y poses.

🔄
Fase 2: Editor de escenas

Canvas 2D para colocar enemigos, items, objetivos. Drag-drop. Export JSON.

📋
Fase 2: Configurador de niveles

Duración, objetivos, enemigos. Formulario con preview JSON.

📋
Fase 3: Design System UI

Visor de tokens (colores, tipografía, espaciado).

📋
Fase 3: Sandbox de testing

Juega cualquier nivel sin npm run dev. Debug mode.
