📥 Exportador de Modelos

Baja cualquier pieza del juego en .glb, ábrela en Blender, retócala y devuélvela. Se exporta el mismo código que corre en la partida.

—

Arrastra para girar · rueda para acercar

  1. Descarga la pieza y ábrela en Blender (File ▸ Import ▸ glTF 2.0).
  2. Edítala sin cambiar el nombre del objeto raíz.
  3. Exporta con File ▸ Export ▸ glTF 2.0 (.glb).
  4. Déjala en public/modelos/piezas/ con el mismo nombre.

El juego prefiere el archivo si existe y usa el procedural si no. No hay que tocar código para cambiar una pieza.
